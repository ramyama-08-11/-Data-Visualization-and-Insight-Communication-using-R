# Week 3 R Statistical Analysis

This project analyzes the UCI Breast Cancer Wisconsin (Diagnostic) dataset with base R. It includes the full analysis script, downloaded source data, a Word report, machine-readable results, and R-generated plots/evidence panels.

## Run the analysis

From this project directory, run:

```powershell
& "$env:LOCALAPPDATA\Programs\R\R-4.6.1\bin\Rscript.exe" analyze_wdbc.R
```

No additional R packages are required. If `data/wdbc.data` is missing, the script downloads the official UCI archive. The analysis uses a fixed random seed, so the split and results are reproducible with the recorded R version.

To rebuild the DOCX after editing the Markdown report, use Pandoc:

```text
pandoc Week3_Statistical_Analysis_Report.md --standalone --toc --number-sections --output=Week3_Statistical_Analysis_Report.docx
```

## Project files

- `analyze_wdbc.R`: end-to-end import, audit, hypothesis tests, cross-validation, logistic model, metrics, outputs, and figures.
- `data/wdbc.data`: UCI source file used in the completed run.
- `outputs/`: captured R console log, session details, model metrics, predictions, summaries, tests, and coefficients.
- `evidence/`: distribution, correlation, ROC, confusion-matrix, and model-diagnostic plots plus source/output image panels generated by R.
- `Week3_Statistical_Analysis_Report.docx`: editable report with embedded figures and analysis.
- `Week3_Statistical_Analysis_Report.md`: report source.

## Data attribution
